# Анализ каталога фильмов

Учебный проект на Python 3.12. Решение по этапам добавляется в
`catalog_analysis.py`. Пока скрипт выводит проверочное приветствие.

## Запуск

Установите [uv](https://docs.astral.sh/uv/getting-started/installation/),
затем выполните в папке проекта:

```sh
uv sync
uv run catalog_analysis.py
```

Ожидаемый вывод на этапе инициализации:

```text
Hello from catalog_analysis.py!
```

## Проверка кода

```sh
uv run ruff check .
uv run ruff format --check .
```

Ruff — единственная внешняя зависимость, установленная только для разработки.
Виртуальное окружение `.venv` создаётся автоматически и не попадает в Git.
После каждого завершённого этапа сохраняйте отдельный коммит.

Проект создан без упаковки командой
`uv init --python 3.12 --no-package --name catalog-analysis .`.
В новых версиях uv флаг `--no-package` сохраняет структуру с одним скриптом
без каталога `src/`.
