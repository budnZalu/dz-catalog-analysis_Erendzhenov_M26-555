# Анализ каталога фильмов

Автор: **Эрендженов (Erendzhenov)**.

Группа: **M26-555**.

[Репозиторий проекта](https://github.com/budnZalu/dz-catalog-analysis_Erendzhenov_M26-555).

Учебный проект на Python 3.12: анализ каталога из 10 фильмов без библиотек
анализа данных. Все девять этапов реализованы функциями в `catalog_analysis.py`.
Единственный импорт в решении — стандартный модуль `math`.

## Запуск

Установите [uv](https://docs.astral.sh/uv/getting-started/installation/),
затем выполните в папке проекта:

```sh
uv sync
uv run catalog_analysis.py
```

Скрипт вызывает `build_report(movies)` и печатает статистику, топ-3, жанры,
категории фильмов, фильмографии актеров и результаты обхода каталога циклами
и генератором. Контрольные значения для исходных данных:

```text
Средний рейтинг: 7.2
Средний возраст фильмов: 8 лет
Фильмов длиннее 120 минут: 4
Суммарная длительность фильмов с рейтингом выше 7: 713 мин
```

Топ-3: The Quiet Algorithm, Midnight In Oslo, The Dune Chronicles.
Жанры: drama — 5, comedy — 3, sci-fi — 3, thriller — 3, action — 2, mystery — 1.

Возраст считается относительно 2026 года; у `catalog_age_stats` этот год
можно изменить параметром `current_year`. Функции средней оценки и возраста
ожидают непустой каталог. `build_report([])` выводит сообщение «Каталог пуст.».
Исходные названия сохранены: нормализация применяется при выводе описаний.

## Проверка кода

```sh
uv run ruff --version
uv run ruff check .
uv run ruff check catalog_analysis.py
uv run ruff format --check .
```

Ruff — единственная внешняя зависимость, установленная только для разработки.
Виртуальное окружение `.venv` создаётся автоматически и не попадает в Git.
Для Ruff включены правила `E`, `F`, `I`, длина строки 88 и целевая версия
Python 3.12. Каждый завершенный этап сохранен отдельным Git-коммитом.

Проверить ветку `while/else`, когда шедевров нет, можно отдельно:

```sh
uv run python -c 'from catalog_analysis import movies, print_first_masterpiece; print_first_masterpiece(movies[:7])'
```

Ожидаемый результат: `Шедевров не найдено`.

Для создания такого проекта без упаковки:

```sh
uv init --python 3.12 --no-package --name dz-catalog-analysis-erendzhenov-m26-555 .
```

В новых версиях uv флаг `--no-package` сохраняет структуру с одним скриптом
без каталога `src/`.
